# Project Instructions

## AI-DLC Workflow

For each work item, use the matching folder under `aidlc-docs/` and keep the workflow artifacts updated:

1. Capture requirements and acceptance criteria in `01-requirements.md`.
2. Document the approved solution in `02-design.md`.
3. Define verification scenarios in `03-test-cases.md`.
4. Implement the work and record the outcome in `04-dev-summary.md`.
5. Validate the changes and record results in `05-qa-report.md`.
6. Document build and deployment details in `06-pipeline-notes.md`.
7. Prepare release information in `07-release-notes.md`.

Use the role guidance in `.claude/agents/` when performing each stage. Do not record secrets in project documentation.
